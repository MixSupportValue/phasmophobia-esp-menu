## 🧩 About

**Phasmophobia Trainer** is a curated list of Phasmophobia open-source tools:

- **Mod Menus** — ESP, ghost visibility, item spawner, sanity control, speedhack, teleport
- **UI Automation Bots** — auto-evidence logger, journal helper, input assistants for single-player study
- **Quality-of-Life Mods** — ghost model viewer, map overlay, loot tracker, HUD enhancements
- **Research Frameworks** — training layouts and config notes for educational use

Based on publicly available community tools like **PhasmoESP**, **GhostHack**, and **QoLMod**.
